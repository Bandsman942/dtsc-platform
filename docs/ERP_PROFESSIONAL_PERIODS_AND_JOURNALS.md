# Exercices, périodes et journaux professionnels

## Exercices et périodes

Un exercice regroupe des périodes comptables non chevauchantes. Les périodes doivent rester comprises dans les dates de l’exercice.

Statuts visibles :

- Ouverte ;
- Clôture provisoire ;
- Fermée ;
- Verrouillée ;
- Réouverte exceptionnellement.

Une période fermée bloque les nouvelles écritures et mutations interdites. La réouverture exige une permission spécifique, un motif, un acteur indépendant et une piste d’audit.

## Journaux

Les journaux réellement supportés couvrent notamment les ventes, achats, banque, caisse, mobile money, paie, stock, immobilisations, fiscalité, ouverture et opérations diverses.

Chaque journal possède : code, libellé, type, préfixe de séquence, statut et politique d’approbation.

## Contrôles

- aucune période chevauchante ;
- aucune écriture hors période ;
- aucun journal d’un autre tenant ;
- aucune utilisation d’un journal inactif ;
- aucune séquence réutilisée ;
- les journaux utilisés sont désactivés plutôt que supprimés.
