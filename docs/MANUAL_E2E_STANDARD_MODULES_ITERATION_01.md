# E2E manuels — Modules standards — Itération 1

**Statut : NON_EXÉCUTÉ**

## 1. Navigation globale

Se connecter, vérifier les navigations desktop/mobile, changer de contexte, ouvrir un module global puis entreprise et revenir au Dashboard.

## 2. Navigation multidomaine

Depuis le site public, ouvrir le compte, se connecter, revenir dans l’application, ouvrir Support, revenir dans l’application puis ouvrir la Console avec un utilisateur autorisé.

## 3. Accès refusé

Ouvrir un module sans permission ; vérifier l’absence de fuite, le message, le retour possible et le refus API.

## 4. Plan insuffisant

Avec un plan inférieur, ouvrir un module supérieur ; vérifier l’information commerciale et l’absence d’action non autorisée.

## 5. Session

Modifier la durée d’inactivité, vérifier la persistance, laisser expirer une session de test, vérifier la redirection et la reprise après reconnexion.

## 6. PWA

Installer lorsque supporté, ouvrir en standalone, mettre en arrière-plan, reprendre, vérifier le contexte et les erreurs.

## 7. Web Push

Activer, vérifier la souscription, recevoir une notification, cliquer vers l’objet précis, désactiver puis vérifier la révocation.

## 8. Responsive

Tester 320, 375, 390, 768, 1024 et 1440 px : sidebar, bottom navigation, filtres, KPIs, dialogues, formulaires et messages d’erreur.

## Résultat

Tests E2E manuels préparés — validation du propriétaire en attente
