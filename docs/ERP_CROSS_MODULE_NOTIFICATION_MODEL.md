# Notifications ERP transverses

Chaque notification possède un destinataire réellement concerné, un contexte global/entreprise, un objet précis, une action attendue, un deep link, une clé de déduplication et un statut de lecture.

Les invitations d’entreprise sont visibles dans le contexte global avant l’adhésion. Les notifications RH et Health sensibles restent génériques. Une mention ou un commentaire d’action ouvre le fil exact. Après révocation, le deep link réévalue les droits et refuse l’accès sans révéler le contenu.

La déduplication utilise le fait métier et le destinataire, pas seulement le texte affiché.

La confidentialité est réévaluée avant chaque lecture.
