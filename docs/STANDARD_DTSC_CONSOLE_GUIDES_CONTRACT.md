# Contrat des guides Console

Les guides de l’itération 7 sont dans `lib/user-guides/iteration07-guides.ts` et sont rendus par `components/user-guides/contextual-user-guide.tsx`.

Chaque guide possède code, locale, titre, résumé, audience, capacités, étapes, avertissements, limitations et date d’actualisation. Les guides décrivent seulement les fonctions réellement implémentées. Le Kanban conserve le guide `COMMERCIAL_MATURITY_KANBAN` de l’itération 5 afin d’éviter un doublon.
