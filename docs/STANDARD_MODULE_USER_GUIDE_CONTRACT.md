# Contrat des guides utilisateurs des modules standards

Chaque guide futur couvre au minimum :

1. objectif ;
2. public concerné ;
3. prérequis ;
4. rôles et permissions ;
5. accès ;
6. vue générale ;
7. création ;
8. détail ;
9. modification ;
10. actions ;
11. statuts ;
12. documents ;
13. commentaires ;
14. notifications ;
15. liens profonds ;
16. usage mobile ;
17. sécurité et confidentialité ;
18. erreurs fréquentes ;
19. limites ;
20. support.

## Interdictions

- documenter une fonction fictive ou planifiée comme active ;
- réutiliser le même guide générique pour des modules différents ;
- exposer des noms de tables, secrets, routes sensibles ou détails internes inutiles ;
- laisser un lien de guide mort ;
- promouvoir un module professionnel sans guide exact.

Le guide est relié au module par `userGuidePath` dans le registre canonique et contrôlé par l’audit des guides.
