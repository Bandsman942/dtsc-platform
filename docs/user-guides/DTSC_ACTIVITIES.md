# Guide utilisateur — Activités DTSC

## Rôle du module

**Activités DTSC** est l'espace de travail interne des collaborateurs reconnus par un dossier RH actif. Il réunit les objets qui les concernent dans les domaines COO, CEO, SCO, MPO, CTO, juridique et paie, sans donner automatiquement accès à toutes les sections d'administration.

## Conditions d'accès

Vous devez :

- être connecté dans le contexte `DTSC_INTERNAL` ;
- posséder un dossier collaborateur actif ;
- avoir un poste officiel reconnu.

Les vues et actions varient selon votre poste, votre responsabilité et votre implication dans l'objet.

## Tableau de travail

Le tableau de bord peut réunir notamment :

- tâches et opérations COO ;
- demandes inter-départements et blocages ;
- réunions et rapports opérationnels ;
- workflows partagés ;
- paies personnelles ;
- objectifs et suivis CEO ;
- demandes collaboratives ;
- achats, inventaires, actifs et logistique SCO ;
- projets et livrables MPO ;
- projets et tâches CTO ;
- dossiers, contrats, risques et demandes juridiques.

Les superviseurs autorisés voient un périmètre plus large ; les autres collaborateurs voient les objets auxquels ils participent.

## Tâches et opérations

Consultez vos tâches, démarrez le travail, signalez un blocage, ajoutez les informations demandées et terminez lorsque le livrable est prêt. Les validations et corrections suivent les actions réellement offertes dans le domaine COO.

## Demandes et collaboration

Vous pouvez soumettre une demande à une section ou à un collaborateur autorisé sans ouvrir directement l'administration sensible. Le demandeur et le destinataire suivent le statut et les commentaires dans le même objet.

## Réunions et rapports

Les réunions auxquelles vous participez sont visibles avec leur ordre du jour, leurs informations de planification et leur compte rendu disponible. Les rapports que vous produisez ou recevez restent liés à leur domaine source.

## Projets spécialisés

Les postes MPO, CTO, SCO, Legal Advisor et autres postes concernés accèdent aux projets ou dossiers auxquels ils sont liés. Les permissions reposent sur le poste RH officiel et l'implication enregistrée, jamais sur un simple intitulé visuel.

## Commentaires, documents et notifications

Les commentaires importants doivent rester dans DTSC Platform. Les documents utilisent les stockages et permissions de leur module source. Une affectation, une mention, une réunion ou une demande peut produire une notification ouvrant l'objet exact.

## Calendrier

Les tâches, réunions et échéances intégrées peuvent apparaître dans le Calendrier. L'objet reste modifié dans son module canonique.

## Limites

- Activités DTSC est une vue de travail transverse ; elle ne remplace pas les consoles spécialisées des responsables.
- Les anciens domaines COO, CTO, MPO, SCO et Legal conservent leurs modèles historiques lorsqu'ils n'ont pas encore été convergés vers le socle entreprise.
- Tous les objets ne prennent pas encore en charge les checklists, versions de soumission ou liens documentaires standardisés.
