# Guide utilisateur — Signalement et modération

Utilisez **Signaler** pour un message, une annonce ou un commentaire problématique. Choisissez un motif exact et ajoutez une description utile. Le signalement n’est visible que par les modérateurs autorisés.

Les modérateurs peuvent masquer, restaurer, supprimer logiquement ou clôturer un signalement avec une décision. Un administrateur de groupe ne modère pas les contenus globaux. Toutes les décisions sont auditées.
