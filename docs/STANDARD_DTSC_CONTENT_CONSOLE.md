# Console contenus publics et promotions

Les publications ont un cycle `DRAFT`, `PUBLISHED`, `ARCHIVED`, une locale, un historique `PublicPublicationVersion` et une prévisualisation protégée utilisant le rendu HTML assaini. Une suppression Console archive ; elle ne détruit pas l’historique.

Les bannières conservent audience, surfaces, période, priorité, CTA, dismissals et état. Les statistiques affichées proviennent des dismissals persistés. Aucune campagne newsletter n’est envoyée sans le moteur existant et ses contrôles.
