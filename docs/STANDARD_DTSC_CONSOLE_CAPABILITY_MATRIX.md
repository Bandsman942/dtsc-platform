# Matrice des capacités Console

| Domaine | Lecture | Gestion |
|---|---|---|
| Vue générale | `CONSOLE_OVERVIEW_READ` | — |
| Utilisateurs | `CONSOLE_USERS_READ` | `CONSOLE_USERS_MANAGE` |
| Organisations | `CONSOLE_ORGANIZATIONS_READ` | `CONSOLE_ORGANIZATIONS_MANAGE` |
| Abonnements | `CONSOLE_SUBSCRIPTIONS_READ` | `CONSOLE_SUBSCRIPTIONS_MANAGE` |
| Support | `CONSOLE_SUPPORT_READ` | `CONSOLE_SUPPORT_MANAGE` |
| Contenu | `CONSOLE_CONTENT_READ` | `CONSOLE_CONTENT_MANAGE` |
| Sécurité | `CONSOLE_SECURITY_READ` | `CONSOLE_SECURITY_MANAGE` |
| Paramètres | `CONSOLE_SETTINGS_READ` | `CONSOLE_SETTINGS_MANAGE` |
| Maturité | `CONSOLE_MODULE_MATURITY_READ` | `CONSOLE_MODULE_MATURITY_MANAGE` |
| Exports | — | `CONSOLE_AUDIT_EXPORT` |
| Réconciliation | — | `CONSOLE_RECONCILE_BILLING` |
| Webhook | — | `CONSOLE_WEBHOOK_RETRY` |

Les capacités sont exposées dans le catalogue de permissions individuelles et vérifiées côté serveur.
