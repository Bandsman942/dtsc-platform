# Modèle d’évaluation IA

Les évaluations couvrent français, anglais, changement de langue, documents multilingues, recherche entreprise, outils, permissions, refus, citations, isolation tenant, données sensibles, fallback et quotas.

Le feedback persistant utile/non utile existant est conservé. Les catégories cibles sont réponse incorrecte, citation incorrecte, outil incorrect, contenu inapproprié et limite non signalée.

Une évaluation automatique peut fournir une preuve de qualité, mais ne remplace pas les E2E du propriétaire ni la validation humaine d’une réponse critique.
