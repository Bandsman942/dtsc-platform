# Modèle documentaire transverse

Les pièces utilisent un upload réel et le service documentaire privé. Une URL libre ne remplace pas le stockage contrôlé.

Chaque document conserve : organisation, auteur, version, date, statut, classification, objet(s) lié(s), historique et droit de téléchargement. Les classifications minimales sont général, commercial, financier, RH, médical, réglementaire et confidentiel.

Un document peut être lié par relation structurelle à contrat, commande, livraison, facture, paiement, projet, livrable, employé, actif, patient, consultation, lot ou incident. Le téléchargement réévalue les permissions de chaque objet. Un document médical lié à une facture n’est jamais exposé depuis Finance ; Finance ne voit que la preuve générique autorisée.
